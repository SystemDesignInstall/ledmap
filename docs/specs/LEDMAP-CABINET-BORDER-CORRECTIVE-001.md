# Cabinet borders — corrective 001

Дата: 2026-10-06. Пользователь явно задал исправление: обводка каждого кабинета 1 px внутрь, общий стык 2 px, без тени. Уточнение пользователя: «Всегда 2 px на экране, независимо от zoom». Этот узкий план реализует указанное поведение; этап веса кабинетов остаётся без одобрения и сюда не входит.

База: актуальный `origin/master`, `e735774c92d2e0648b1a783f3cd7a68ca00570fb`. Отдельные ветка/worktree: `feat/cabinet-inset-borders` / `.worktrees/cabinet-inset-borders`. Обязательный preflight выполнен до production-кода.

## Контракт

- Composition chart получает отдельный примитив внутренней обводки всего кабинета вместо верхней/левой полосы и внешних граничных исключений.
- Canvas отрисовывает по одному пикселю backing buffer внутрь всех четырёх сторон. Границы округляются после camera zoom/offset и device pixel ratio. Общая граница соседних кабинетов занимает два пикселя; за границы кабинета обводка не выходит. При размерах кабинета менее двух пикселей стороны естественно перекрываются внутри его видимой площади.
- Тени и blur границы отключены независимо от настроек тени текста. Цвета и переключатель Cabinet lines сохраняются.
- Редакторские Cabinet overlays используют ту же внутреннюю обводку без дополнительного внешнего stroke; pending resize сохраняет dashed preview. Selection / guides / module overlays сохраняют своё отдельное назначение.
- PNG при actual pixel export: 1 px внутрь каждой стороны, 2 px на стыке. SVG содержит такую же геометрию обводки в координатах исходного изображения; масштаб сторонним SVG viewer управляется этим viewer.
- Core, project intent, сериализация и schema version не меняются. Исправление относится к app drawing / renderer.

## Приёмка

Независимая проверка пикселей на горизонтальном и вертикальном стыке, наружная граница 1 px и отсутствие halo/alpha вне границы. Сравнение при zoom 0.5 / 1 / 2 и DPR 1 / 2; text shadow ON не добавляет тень границам; Cabinet lines OFF и mask сохраняют прежнее поведение. Проверка PNG/SVG. Полные unit-тесты, typecheck, lint, build и Electron smoke. Исходный пользовательский worktree и открытый несохранённый проект сохраняются.
