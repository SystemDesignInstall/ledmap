# Cabinet label overlay corrective

Этап начат 2026-10-06, продолжен 2026-10-07. Основание: прямое указание пользователя убрать верхние подписи кабинетов, которые накладываются на крупные подписи Screen Drawing.

База: актуальный `origin/master`, `7dc3acb90f990ec75eb6d3025dedb48d3720d066`. Ветка: `feat/cabinet-label-overlap`; выделенный worktree, обязательный preflight выполнен.

## Одобренный узкий план

В Composition каждый кабинет получает одну подпись в центре. Если Screen Drawing уже рисует Cabinet labels, Cabinet IDs, Coordinates или Grid address, мелкие редакторские подписи Cabinet overlay не рисуются. Выбор определяется отдельно для каждого Screen.

Крупные подписи сохраняют выбранные текст, размер и Text shadow. Редакторские подписи остаются доступными при Labels = None или Name and size. Геометрия Cabinets / Modules, выбор, hover, переименование, Clean View и PNG/SVG сохраняют существующие контракты. Core и формат проекта не меняются.

- Zoom 47%, 100%, 207% (скриншот пользователя), 800%; editor / Clean View; два Screen с разными настройками; Cabinet overlay ON / OFF.
