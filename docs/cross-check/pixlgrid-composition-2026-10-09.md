# PixlGrid ↔ LedMAP Composition: аудит 2026-10-09

## Источники и предел проверки

- Установленный Windows PixlGrid: пакет `7087VideoWalrus.pixlgrid`, версия `2.220.1727.0`. Процесс запущен, окно `Editor` доступно для выбора через Computer Use.
- Две попытки захвата окна через Computer Use завершились `window capture timed out: timed out waiting on channel`. Поэтому поведение UI PixlGrid, точные пиксели PNG, содержимое `.pg3` и пригодность экспортов в целевых программах **не проверены**.
- Локальные `PiXLGrid.pref` и `LEDType.lts` доступны для чтения; сохранённого `.pg3` и экспортов PixlGrid в каталоге приложения нет.
- Публичное описание и история функций: [PixlGrid в App Store](https://apps.apple.com/us/app/pixl-grid/id1445330973?mt=12). Это сведения разработчика, а не результат наших интерактивных тестов.
- Статусы LedMAP ниже относятся к интеграционной ветке `feat/composition-sparse-integration` от `origin/master`. Изменения ещё не входят в `master`.

## Что изменить следующим

1. В PixlGrid собрать эталоны на одном Canvas: сетка 4×3, два grid, два скрытых tile, половинный крайний ряд и столбец, разные палитры, mask offset 0/8, сохранённый `.pg3`, PNG и все доступные экспорты. Записать версии, размеры и наблюдаемое поведение. До получения этих файлов **не** строить адаптеры `.pg3`, Millumin и AE по догадкам.
2. Сверить физическое удаление Cabinet с поведением PixlGrid по эталонному `.pg3`. Скрытие изображения tile держать отдельным свойством Screen drawing, если `.pg3` подтвердит именно графическое скрытие.
3. Проверить маску из интеграционной ветки на эталонных PNG. Положительное значение сейчас уменьшает белую область на X и Y; отрицательное расширяет там, где есть физический Cabinet.
4. Спроектировать смешанную геометрию крайних Cabinet с независимыми физической позицией, логическим порядком и Mapping Region. Нужны миграция сериализации, lookup пикселей, Hardware и тесты Reference 001–004.
5. Добавить Live Output cursor modes и валидируемый импорт `.lts` с массой, мощностью, яркостью и физическим размером. Отображать сумму и единицы измерения только по подтверждённым данным.
6. Проверять внешние экспорты в самих Resolume, Millumin и After Effects. Успешная генерация XML/SVG/скрипта в LedMAP не доказывает, что целевая программа его принимает.
